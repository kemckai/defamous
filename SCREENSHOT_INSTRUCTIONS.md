# Screenshot Instructions for Chrome Web Store

You'll need at least 1 screenshot (up to 5 recommended) showing Defamous in action.

## Screenshot Requirements

- **Size**: 1280x800 pixels OR 640x400 pixels
- **Format**: PNG or JPEG
- **Quantity**: Minimum 1, up to 5 recommended
- **Content**: Must show the extension working on Facebook

## Recommended Screenshots

### Screenshot 1: Main Feed View (REQUIRED)
**What to show:**
- Facebook feed with the extension active
- Some posts visible (preferably showing filtered vs non-filtered)
- Extension icon visible in browser toolbar
- Clean, professional view of the feed

**How to capture:**
1. Open Facebook.com in Chrome
2. Install and enable Defamous extension
3. Scroll to your feed
4. Take a screenshot showing the feed with extension active
5. Crop/edit to 1280x800 or 640x400

### Screenshot 2: Extension Popup (RECOMMENDED)
**What to show:**
- Click the Defamous icon
- Show the popup with all filter settings visible
- Shows the customization options available

**How to capture:**
1. Click Defamous icon in toolbar
2. Make sure all settings are visible in popup
3. Take screenshot of the popup
4. May need to use browser screenshot tool to capture popup

### Screenshot 3: Before/After Comparison (OPTIONAL)
**What to show:**
- Split view or side-by-side showing filtered vs unfiltered feed
- Demonstrates the filtering in action

### Screenshot 4: Settings Interface (OPTIONAL)
**What to show:**
- Close-up of the popup settings
- Highlight the various filter options

### Screenshot 5: Different Facebook Pages (OPTIONAL)
**What to show:**
- Extension working on different Facebook pages (timeline, groups, etc.)

## Tools for Creating Screenshots

### Mac:
- Built-in screenshot tool: `Cmd + Shift + 4` to select area
- Or use Preview to edit/crop images
- Can use browser's Developer Tools (F12) to simulate specific screen sizes

### Chrome/Edge Built-in:
1. Open Developer Tools (F12)
2. Click device toolbar icon (mobile icon)
3. Set custom dimensions (1280x800 or 640x400)
4. Take screenshot

### Online Tools:
- Use a tool like Canva to create polished screenshots
- Add text annotations if helpful
- Ensure dimensions are correct

## Tips

1. **Hide Personal Info**: Make sure to blur/remove any personal information from screenshots
2. **Professional Look**: Keep screenshots clean and focused
3. **Show Value**: Screenshots should clearly show what the extension does
4. **Consistent Style**: Keep all screenshots with similar styling
5. **File Names**: Name files clearly (e.g., `defamous-screenshot-1.png`)

## Example Workflow

1. Open Facebook.com
2. Enable Defamous extension
3. Adjust browser window to appropriate size (1280x800 or 640x400)
4. Navigate to your feed
5. Take screenshot
6. Edit/crop to exact dimensions
7. Save as PNG or JPEG
8. Repeat for additional screenshots

## File Naming Convention

```
defamous-store-screenshot-1-main-feed.png
defamous-store-screenshot-2-popup.png
defamous-store-screenshot-3-comparison.png
```

Save these in your extension directory for easy access when submitting to the Chrome Web Store.
