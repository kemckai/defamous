# Icon Files Required

The extension requires three icon files for the browser toolbar:
- `icon16.png` (16x16 pixels)
- `icon48.png` (48x48 pixels)
- `icon128.png` (128x128 pixels)

## Creating Icons

You can create simple icons using any image editor:

1. **Option 1: Use an online icon generator**
   - Visit https://www.favicon-generator.org/ or similar
   - Upload a simple image or create one
   - Generate icons in the required sizes

2. **Option 2: Create simple placeholder icons**
   - Use any image editor (Photoshop, GIMP, Canva, etc.)
   - Create a simple design (e.g., a "no" symbol with a star, or just text "NC")
   - Export in the three required sizes

3. **Option 3: Use a simple colored square (temporary)**
   - Create 16x16, 48x48, and 128x128 pixel images
   - Fill with a color like #1877f2 (Facebook blue) or #ff0000 (red for "no")
   - Save as PNG files

## Quick Placeholder Solution

If you just want to test the extension quickly, you can:
1. Create a simple 128x128 PNG with any solid color
2. Resize it to create the 48x48 and 16x16 versions
3. Name them `icon128.png`, `icon48.png`, and `icon16.png`

The extension will work without icons, but you'll see a default puzzle piece icon in Chrome/Edge.
